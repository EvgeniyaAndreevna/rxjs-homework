# Проверка домашнего задания № 11

## Обязательное: Polling

1. Запустить `npm.cmd run server`, затем `npm.cmd start` в другом терминале.
2. В настройках выбрать `REST API`, адрес оставить пустым.
3. Открыть DevTools → Network → фильтр `unread`. Проверить запрос `GET /messages/unread` и статус 200.
4. Подождать 5 секунд. Проверить повторный запрос, новые письма выше старых.
5. Убедиться, что тема обрезается до 15 символов + `…`, дата `ЧЧ:ММ ДД.ММ.ГГГГ`.
6. Остановить backend (Ctrl+C). Подождать 5-10 секунд: письма остаются, приложение не падает, запросы продолжаются.
7. Запустить backend снова: новые сообщения продолжают добавляться.

## Дополнительно: Posts with comments

1. Нажать «Публикации».
2. Убедиться, что комментарии есть под каждым постом (не более 3).
3. В DevTools проверить `GET /posts/latest` и три запроса `/posts/:id/comments/latest`.
4. Нажать «Обновить».

## Дополнительно: Project Management Dashboard

1. Нажать «Проекты».
2. Выбрать `iOS App`, отметить `Apple Pay Support`.
3. Убедиться, что уменьшилось число открытых задач у проекта и общий счётчик.
4. Снять отметку: показатели должны вернуться.

## GitHub Pages

1. Проверить зелёный `Deploy GitHub Pages` во вкладке Actions.
2. Открыть публичную ссылку на опубликованный сайт.
3. Проверить, что по умолчанию активен демо-режим, изображения, стили и скрипты загружаются.
4. Если backend размещён в интернете, в настройках включить `REST API`, указать HTTPS-домен и проверить HTTP-запросы.
